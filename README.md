# DOCUMEET - ADMIN DASHBOARD

Web quản trị là giao diện quản trị của hệ thống DocuMeet - nền tảng quản lý cuộc họp nội bộ. Dashboard được xây dựng responsive, cung cấp các module quản lý người dùng, quản lý đơn vị tổ chức và đăng ký thiết bị truy cập hệ thống.

Về mặt bảo mật, ứng dụng triển khai xác thực và quản lý phiên đăng nhập phía frontend bằng access token / refresh token, kết hợp xác minh thiết bị mới qua OTP, giúp phiên làm việc của quản trị viên luôn liền mạch và an toàn.
